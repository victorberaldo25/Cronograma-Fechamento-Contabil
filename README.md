## 1. O Problema de Negócio
O fechamento contábil e fiscal de grandes empresas envolve dezenas de tarefas interdependentes executadas por diferentes áreas dentro de uma janela de poucos dias úteis (`D-5` a `D+5`). Atrasos em um setor geram efeito cascata, atrasando a entrega da DRE para o conselho e auditorias.
Este sistema atua como o **orquestrador visual** do cronograma de fechamento, garantindo que gestores identifiquem antecipadamente tarefas em risco de estouro de prazo.

## 2. Como Executar
1. Clone o repositório:
   ```bash
   git clone https://github.com/<seu-usuario>/fechamento-contabil-orquestrador.git
   cd fechamento-contabil-orquestrador
   ```
2. Abra `index.html` no navegador ou rode localmente com `npx serve . -l 8080`.
